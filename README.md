# Claude Code Handbook

Unofficial 18-chapter field guide to **Claude Code**, Anthropic's terminal-based agentic coding CLI. Covers first install through CLAUDE.md, skills, hooks, MCP, subagents, context engineering, and multi-agent orchestration.

**Read it here:** [https://reinamoon.github.io/claude-code-handbook/](https://reinamoon.github.io/claude-code-handbook/)

Independent community reference. Not affiliated with or endorsed by Anthropic. Commands, defaults, and pricing change. Verify anything load-bearing against the [official Claude Code docs](https://code.claude.com/docs).

## What this covers

| Part | Chapters |
|------|----------|
| Foundations | Basics and installation, permissions and Plan Mode, models, slash commands, CLAUDE.md |
| Extension | Auto memory, subagents, skills, hooks, MCP and plugins |
| Engineering practice | Orchestration, context engineering, harness and loop engineering, prompt guide |
| Beyond the terminal | Desktop and web, playground, appendix, references |

Search terms this handbook is written around: Claude Code tutorial, CLAUDE.md, Claude Code skills, hooks, MCP servers, subagents, agentic coding, Anthropic CLI.

## How to use the repo

The live site is a single `index.html` page (GitHub Pages). Open that file locally, or clone and browse:

```bash
git clone https://github.com/ReinaMoon/claude-code-handbook.git
open index.html
```
